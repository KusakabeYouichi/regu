# 「コピーしました」の UI テスト

## 要求事項

- E11 が時々落ちる(c09 の申し送り)。意味のあるテストになるように直す

## 原因

- 表示時間が 1.5 秒しかなく、「出たのを検出してから押し直す」までに 1.5 秒を超えると、押し直す前に消えて落ちる
- 1.5 秒では「表示時間の数え直し」と「新しく出た」の差が XCUITest の遅れと同じ大きさで、判定に意味が薄い
- E14(ホームから戻ると消える)も同じ理由で、戻るまでに時間で消えてしまい、背面に回ったときに消す処理を確かめられていなかった

## 実装

- `MainView.badgeDuration`: DEBUG ビルドに限り、起動引数 `-reguUITestBadgeSeconds <秒>` で表示時間を延ばせる(既存の `-reguUITestReset` と同じ UI テスト専用の口。引数ドメインなので保存されない)。既定は 1.5 秒のまま
- E11: 表示時間 8 秒で起動。1 回目の押下から 4 秒後にまだ出ていることを確かめて押し直し、消えた時刻を 0.1 秒刻みで測って「2 回目の押下から 6.5 秒以上」を確かめる(数え直さない実装なら約 5.3 秒以下、数え直す実装なら 8 秒以上)。押し直す前に変換ボタンが押せることを確かめる
- E11b(新規): 既定の表示時間では 5 秒以内に消える(上限だけ)
- E14: 表示時間 8 秒で起動し、7 秒未満で戻れたことを確かめてから「消えている」を見る

## 検証

- E11 を 5 回連続で実行して 5 回成功
- 赤を先に見る:
  - `badgeHideTask?.cancel()` を外すと E11 が 2 回とも「数え直されていない」(2 回目の押下から 4.4 秒・4.5 秒で消えた)で失敗
  - 既定の表示時間を 15 秒にすると E11b が失敗
  - 背面に回ったときの `hideCopiedBadge()` を外すと E14 が失敗(変更前の E14 は 1.5 秒で消えるため、この壊し方を捕まえられなかった)
- E14 を 3 回連続で実行して 3 回成功
- XCUITest(iPhone 全件)成功・失敗 0

## テストを読む役の指摘と処分

| # | 指摘 | 処分 |
|---|---|---|
| 1 | 既定の 1.5 秒で消えることを確かめるテストが無くなる | 修正(E11b を追加) |
| 2 | 2 回目の押下が効かないと「数え直されていない」と取り違える | 修正(押す前に押せることを確かめる) |
| 3 | 本体の口が `#if DEBUG` で囲まれていない(既存の口と不揃い) | 修正 |

## 残課題 / 申し送り

- E1・E12・E13 などの「押した直後に出る」(2 秒以内)の確認は既定の 1.5 秒のまま。今回の実行では落ちていないが、同じ遅れで落ちることがあれば同じ口で延ばす
