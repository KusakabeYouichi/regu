# ビルトインのプリセットの別名(alias)

## 要求事項

ユーザーが作るプリセットに名前を付けられるのと同じように、ビルトインの 3 つにも別名を付けられるようにする。別名は日本語も可で、長すぎたら文字を小さくする。
別名があれば選択リストには別名を出し、設定の一覧には「本当の名前 - 別名」と出す。
途中の決定: 用語のフランス語化(Préréglages / Personnalisés / Paramètres)とソースの改名は後回し。表示の日本語だけ「既定」→「ビルトイン」、「ユーザー」→「ユーザー設定」。
かっこは半角 () を使う(リポジトリ全体を直す)。

## 対応スコープ

- 対象: 別名の保存と表示(チップ・メニュー・一覧・編集画面)、見出しの文言、全角かっこ「（）」の半角化(リポジトリ全体)
- 対象外: フランス語の用語とソースの改名(後回し)、ユーザープリセットへの別名(名前そのものを変えられる)

## 参照した仕様

- 設計: `.claude/hataraku/progress/c03-design.md`(作業用)、テスト観点 `c03-tests.md`

## 実装概要

- ReguCore `PresetStore` に別名の辞書(private)を持ち、公開は `alias(for:)` / `setAlias(_:for:)` / `displayName(for:)` / `listName(for:)`。保存キー `regu.builtInAliases` を追加し、既存のキーは変えていない
- 別名は Preset・変換設定・クリップボードの指紋に入れない(自動変換の判定に影響しない)

## 主要な実装の詳細

### 別名の規則
- 変更ファイル: `Sources/ReguCore/PresetStore.swift`
- 前後の空白を除く。空・空白だけ・本当の名前と同じなら別名なし。ビルトイン以外の ID は無視。他のプリセット名と同じ別名は許す(選択は ID)
- 保存時と読み込み時で同じ規則(`normalizedAlias`)を使い、値が変わらなければ保存も変更通知もしない
- **なぜそうしたか**: 段 5 の指摘(読み込み時に整えないと「régularisation - régularisation」や空白付きが出うる、確定・フォーカス喪失・画面を閉じるで最大 3 回保存していた)

### 表示
- 変更ファイル: `MainView.swift`, `PresetListView.swift`, `PresetEditorView.swift`
- チップ・メニュー・VoiceOver の値は別名優先(`displayName`)。チップは 1 行で最小 70% まで縮小、入らなければ末尾省略
- メニューの項目は OS が描くため縮小できない(長い別名の折り返し・省略は OS 任せ)
- 一覧はビルトインを「本当の名前 - 別名」(`listName`、区切りは半角スペース + ハイフン)。1 行で縮小 → 末尾省略。行に `presetRow.<uuid>` の識別子
- 編集画面(ビルトイン): 本当の名前と、「別名」の見出し付きの入力欄。保存は確定・フォーカスを外したとき・画面を閉じるとき(日本語の変換途中は保存しない)
- 見出し「既定」→「ビルトイン」、「ユーザー」→「ユーザー設定」

### 全角かっこの半角化
- リポジトリの追跡ファイル 38 本で「（）」を「()」に置き換えた。変換のテストデータ(`ConverterSingleSettingTests.swift` の F1 の入力 `！＃＄＼～（）`)だけは全角の変換対象なので残した
- 別名の対応で触っていない 32 本は、変更前の内容のかっこだけを置き換えたものと一致することを照合した
