# 何も変えなかった新しいプリセットを追加しない

## 要求事項

- 「+」で新しいプリセットを作ったとき、設定がすべて preserve のままで名前も変えなかったら、ユーザー設定に追加しない
- 途中で変えても、元に戻して結局何も変わっていなければ追加しない
- 編集画面の見出し「名前」を「nom」にする
- 「+」を、プリセット一覧の「ユーザー設定」の見出しの隣に置く

## 主要な実装の詳細

- `PresetStore.discardIfUntouched(_:defaultName:)`(ReguCore): ユーザープリセットの名前が既定名のままで、設定が全 preserve なら消して true。判定は呼んだときの状態だけで行うので、変えて戻したものも消える
- `PresetListView`: 「+」で作った ID を覚え、その編集画面が消えきったとき(戻る・一覧ごと閉じる)に上を呼ぶ。「+」はツールバーから「ユーザー設定」の見出しの右端へ移した(押せる大きさ 44pt)
- `PresetEditorView`: 見出しと名前欄のプレースホルダーを「nom」に
- **なぜそうしたか**: 編集画面は保存先の値を直接編集する作りなので、「作ってから、何も変わっていなければ消す」にすると既存の編集の流れを変えずに済む。判定を ReguCore に置いて単体テストで固定した
- 対象は「+」で作った 1 件だけ。複製で作ったもの・既存のユーザープリセットは対象外(要求に無い)

## 検証結果

| 内容 | 結果 |
|---|---|
| `swift test` | 98 件が緑(N1〜N5 を追加) |
| E16(新): 見出しの隣の +、nom、何も変えず戻る/設定を変えて戻す/編集中に一覧ごと閉じる → 追加されない、名前を変えたものは残る | 緑。旧 PresetListView では 4 か所が赤 |
| UI テスト全件(iPhone 17 Pro Max、最後の修正の後) | 16 件が緑(iPad 専用の E8 は飛ばした) |
| 目視 | + が朱色で見出しの右端に出ること、払って閉じた後にメイン画面へ戻ることをスクリーンショットで確認 |
