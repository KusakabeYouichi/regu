régu サポート

régu(レギュ)は、コピーした文字列を、選んだプリセットの規則で一度にそろえる iPhone / iPad 用のアプリです。

使い方

  1. 他のアプリで文字列をコピーします。
  2. régu を開きます。選んでいるプリセットで変換され、結果がクリップボードに入ります。
  3. 元のアプリに戻って貼り付けます。

プリセットは、メイン画面のチップで切り替えます。設定ボタンからプリセットの一覧を開き、[ユーザー設定] の [+] で自分のプリセットを作れます。

よくある質問

「ペーストを許可」と出ます
régu はクリップボードを読んで変換するアプリなので、iOS が許可を求めることがあります。iOS の 設定 › アプリ › régu › 他のAppからペースト を「許可」にすると、毎回は出なくなります。
変換されません
régu が自分で書き戻した文字列は、もう一度は変換しません。別の文字列をコピーし直してから開いてください。

プライバシーポリシー

Assistance régu

régu est une app pour iPhone et iPad qui remet en ordre, en une seule fois, le texte copié selon le préréglage choisi.

Utilisation

  1. Copiez un texte dans une autre app.
  2. Ouvrez régu : le texte est converti avec le préréglage sélectionné et le résultat est placé dans le presse-papiers.
  3. Revenez dans l’app d’origine et collez.

Changez de préréglage avec la puce de l’écran principal. Depuis le bouton des réglages, ouvrez la liste des préréglages et créez les vôtres avec le [+] de [ユーザー設定].

Questions fréquentes

iOS demande d’autoriser le collage
régu lit le presse-papiers pour le convertir ; iOS peut donc demander l’autorisation. Dans Réglages › Apps › régu › Coller depuis d’autres apps, choisissez « Autoriser ».
Le texte n’est pas converti
régu ne reconvertit pas le texte qu’il vient d’écrire lui-même. Copiez un autre texte, puis ouvrez régu.
