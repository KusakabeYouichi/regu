régu 操作マニュアル

régu(レギュ)は、コピーした文字列を、選んだプリセットの規則で一度にそろえる iPhone / iPad 用のアプリです。このマニュアルでは、基本の使い方から、プリセットの作り方、変換設定の全項目までを説明します。

  1. 第1章régu とはコピーして開くだけでそろえて戻す仕組みと、通信しないこと
  2. 第2章基本の使い方画面の構成、開いたときの自動変換、変換ボタン、結果の選択、横長のときの配置、ペーストの許可
  3. 第3章プリセットビルトインの 3 つ、切り替え、alias、新しく作る・複製する・削除する
  4. 第4章設定リファレンス変換設定の全項目と全選択肢、適用される順番
  5. 第5章困ったときペーストの許可、変換されないとき、ビルトインが編集できないとき など
  6. 付録プライバシーポリシーrégu が扱う情報について(サポートページ)
