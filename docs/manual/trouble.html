第5章困ったとき

よくある疑問と対処です。解決しないときは、お問い合わせください。

「ペーストを許可」と毎回出ます
régu はクリップボードを読んで変換するアプリなので、iOS が許可を求めることがあります。iOS の 設定 › アプリ › régu › 他のAppからペースト を「許可」にすると、毎回は出なくなります(第2章)。
開いても変換されません
régu が自分で書き戻した文字列は、もう一度は変換しません。別の文字列をコピーし直してから開いてください。同じ文字列をもう一度変換したいときは、entrée で変換ボタンを押してください(第2章)。
ほかに、クリップボードの中身が前に読んだときから変わっていないとき、「ペーストを許可」で許可しなかったときも、開き直すだけでは読みません。コントロールセンターなどを閉じて戻ったときも読みません。コピーし直してから開いてください。
プリセットを切り替えたのに結果が変わりません
プリセットを切り替えただけでは変換し直しません。変換ボタンを押してください(第2章)。
変換ボタンを押しても何も起きません
entrée が空か、空白・改行だけのときは変換しません。
ビルトインのプリセットが編集できません
ビルトインのプリセット(régularisation / Adresse héritée / ruby héritée)は、変換設定を変更できず、削除もできません。付けられるのは alias だけです。設定を変えたいときは、プリセットの一覧で行を左へスワイプするか長押しして「複製」し、複製したほうを編集してください(第3章)。
+ で作ったプリセットが一覧にありません
名前も変換設定も変えずに設定画面から戻ると、プリセットは追加されません。名前か変換設定を変えてから戻ってください(第3章)。
「同じ名前のプリセットがあります」と出ます
ほかのプリセット(ビルトインの alias を含む)と同じ名前です。そのままでも保存されますが、チップのメニューで見分けにくくなるので、別の名前にすることをおすすめします。
