第1章régu とは

régu は、コピーした文字列の表記を、あらかじめ決めた規則でそろえるアプリです。規則のまとまりを「プリセット」と呼びます。

コピーして開くだけ

  1. 他のアプリで文字列をコピーします。
  2. régu を開きます。régu はクリップボードの文字列を読み、選んでいるプリセットで変換して、結果をクリップボードへ書き戻します。
  3. 元のアプリに戻って貼り付けます。

régu の画面では、上の欄にコピーした文字列、下の欄に変換した結果が出ます。結果は全選択された状態で表示されるので、内容を確かめられます。

régu が自分で書き戻した文字列は、もう一度は変換しません。開き直すたびに同じ文字列が何度も変換されることはありません。

何をそろえるか

そろえられるのは、全角・半角の英数字と記号、半角カナ、全角スペース、アクセント付きの文字の合成・分解、ひらがな・カタカナ、鉤括弧、単位の組文字(㎏ など)、HTML の文字参照、URL の %XX 表記です。どれをどちらへそろえるかはプリセットごとに決めます。全項目は第4章 設定リファレンスをご覧ください。

はじめから 3 つのプリセット(régularisation / Adresse héritée / ruby héritée)が入っています。自分のプリセットを作ることもできます(第3章)。

通信しません

régu には、ネットワーク通信を行なうコードがありません。クリップボードの内容が端末の外へ送られることはありません。プリセットの一覧にある「使い方(マニュアル)」は、このマニュアルをブラウザで開くだけです(régu 自身は通信しません)。詳しくはプライバシーポリシーをご覧ください。
