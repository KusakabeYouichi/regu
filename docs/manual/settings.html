第4章設定リファレンス

プリセットの設定画面に並ぶ変換設定の全項目です。5 つのグループに 10 項目があり、どの項目にも「preserve」(変えない)があります。新しく作ったプリセットは、すべて preserve から始まります。

表記は設定画面のとおりです。例の「→」の左が変換前、右が変換後です。

latin

alphabet

英字と数字(A〜Z・a〜z・0〜9)の全角と半角(ASCII)を変えます。記号は変えません(記号は symbole)。

選択肢内容例
preserve変えない
JIS X 0208 → ASCII全角の英数字を半角にＡＢＣ１２３ → ABC123
ASCII → JIS X 0208半角の英数字を全角にABC123 → ＡＢＣ１２３

lettre accentuée

アクセント付きの文字を、1 文字に合成した形(NFC)と、元の文字+アクセント記号に分けた形(NFD)の間で変えます。見た目は同じでも、検索や文字数の数え方が変わることがあります。CJK 互換漢字(U+F900〜FAFF、U+2F800〜2FA1F)を含む文字は変えません。

選択肢内容例
preserve変えない
NFC → NFD合成済みの文字を分解するé(U+00E9)→ e + U+0301
NFD → NFC分解された文字を合成するe + U+0301 → é(U+00E9)

espace

space

全角スペース(U+3000)と半角スペース(U+0020)を変えます。

選択肢内容
preserve変えない
U+3000 → U+0020全角スペース 1 個を半角スペース 1 個に
U+3000 → U+0020 × 2全角スペース 1 個を半角スペース 2 個に
U+0020 → U+3000半角スペース 1 個を全角スペース 1 個に
U+0020 × 2 → U+3000半角スペース 2 個を全角スペース 1 個に。左から 2 個ずつ置き換え、余った 1 個は半角のまま残す(半角 3 個 → 全角 1 個+半角 1 個)

les kanas

les katakana

半角カナ(JIS X 0201)と全角カナ(JIS X 0208)を変えます。カナのほか、句読点・鉤括弧・中黒(。「」、・)、長音記号(ー)、濁点・半濁点(゛゜)も対象です。

選択肢内容例
preserve変えない
JIS X 0201 → JIS X 0208半角カナを全角に。後ろの濁点・半濁点と合わせて 1 文字にできるものは 1 文字にするｶﾞｯｺｳ → ガッコウ
ｳﾞ → ヴ
ｰ → ー
｢｣ → 「」
JIS X 0208 → JIS X 0201全角カナを半角に。濁音・半濁音は文字と ﾞ ﾟ に分ける。半角の形が無い文字(ヮ ヵ ヶ ヰ ヱ など)はそのままガッコウ → ｶﾞｯｺｳ
ー → ｰ
「」 → ｢｣

les hiraganas

ひらがなとカタカナ(全角)を変えます。長音記号(ー)、ヷ〜ヺ、半角カナは変えません。

選択肢内容例

symbole

unit

単位を 1 文字にまとめた組文字(㎏ ㎝ ㎡ など)と、英字の表記を変えます。対象は SI 単位などの組文字(㎎ ㎏ ㎜ ㎝ ㎞ ㎡ ㏄ ㎖ ㎐ ㎾ ㎃ ㎈ ㎳ ㍱ ㏈ ㎛ ㏖ など)です。㏒ ㏑ のような SI でない組文字と、㌔ のようなカタカナの組文字は変えません。

選択肢内容例

㎡ → m²
㏄ → cc

適用される順番

1 つのプリセットの中の設定は、次の順番で適用されます。前の段階の結果に、次の段階の変換がかかります。

  1. 前処理(文字参照を戻す・まとめる)
    1. HTML Entity → Code Point
    2. URL Entity → Code Point
    3. ligature → SI
    4. JIS X 0201 → JIS X 0208(les katakana)
    5. NFD → NFC
  2. 文字種の変換: alphabet、space、les hiraganas、symbole、guillemets
  3. 後処理(分ける・符号にする)
    1. NFC → NFD
    2. JIS X 0208 → JIS X 0201(les katakana)
    3. SI → ligature
    4. Code Point → URL Entity
    5. Code Point → HTML Entity

たとえば ruby héritée(les hiraganas: ひらがな→カタカナ、les katakana: JIS X 0208 → JIS X 0201)では、ひらがながカタカナになってから半角になるので、「びびでぃばびでぃぶ」は「ﾋﾞﾋﾞﾃﾞｨﾊﾞﾋﾞﾃﾞｨﾌﾞ」になります。また、HTML Entity → Code Point と alphabet の JIS X 0208 → ASCII を組み合わせると、&#xFF21;(全角の Ａ)は文字に戻ってから半角になり、「A」になります。
